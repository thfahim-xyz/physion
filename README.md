# Physion

A free and open physics learning website focused on clarity, intuition, and mathematical understanding.

Physion is a long-term project aiming to organize physics into a structured, interconnected, and accessible knowledge base; from foundational concepts to advanced theories.

## Topics Covered

* Foundations of Physics
* Mathematical Methods for Physics
* Classical Mechanics
* Continuum Mechanics
* Thermodynamics and Statistical Mechanics
* Electromagnetism
* Optics
* Relativity
* Quantum Mechanics

## Goals

* Explain physics with both intuition and mathematical precision
* Create clean and structured notes for self-study
* Connect concepts across different fields of physics
* Make advanced topics more approachable
* Build a fast, minimal, and mobile-friendly learning experience

## Features

* Organized book-style structure
* Chapter and section navigation
* Responsive design
* Dark mode friendly UI
* Written in Markdown
* Powered by Jekyll and GitHub Pages

## Tech Stack

* HTML/CSS/JavaScript
* Jekyll
* Markdown
* GitHub Pages

## Project Status

Physion is currently under active development.
Some sections may be incomplete or marked as coming soon.

## Philosophy

Physics is not just a collection of equations; it is a way of describing reality.

This project emphasizes:

* Conceptual understanding
* Mathematical consistency
* Critical thinking
* Curiosity-driven learning
