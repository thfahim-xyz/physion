## Notation and Conventions

### Symbology

| Description | Common Symbols |
| --- | --- |
| Number of Cycles | $N$ |
| Linear Frequency | $f, \nu$ |
| Angular Frequency | $\omega$ |
| Period | $T$ |
| Amplitude | $A$ |
| Phase | $\phi, \theta$ |
| Wavelength | $\lambda$ |
| Linear Wavenumber | $\sigma, \bar{\nu}$ |
| Angular Wavenumber | $k$ |
| Linear Wave Vector | $\boldsymbol{\sigma}$ |
| Angular Wave Vector | $\mathbf{k}$ |
| Phase Velocity | $\mathbf v_p$ |
| Group Velocity | $\mathbf v_g$ |
