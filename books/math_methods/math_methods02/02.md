# Multivariable Functions

## Scaler-valued Functions

A scalar-valued function is a function whose output is a scalar (a single numerical quantity).

If the input is a point in space, then the function assigns exactly one number to every point.

$$
    f : D \subseteq \mathbb{R^n} \rightarrow \mathbb{R}
$$

where

- $D$ is the domain,
- $n$ is the number of input variables,
- the output is a single real number.

Many physical quantities (e.g. temperature, mass density, electric potential, pressure, potential energy, etc.) are naturally described by scalar-valued functions.

## Vector-valued Functions

A vector-valued function is a function whose output is a vector.

Instead of returning a single number, it returns several components that together form a vector.

$$
    \mathbf F : D \subseteq \mathbb{R}^n \rightarrow \mathbb{R}^m
$$

A vector-valued function is commonly written as

$$
    \mathbf F = (F_1, F_2, \ldots, F_m)
$$

where each component $F_i$ is a scalar-valued function.

Mant physical quantities (e.g. position, velocity, acceleration, force, electric field, etc.) are described by vector-valued functions.

## Scaler Fields

A **scalar field** is a scalar-valued function whose input is a **point in space**.

It assigns one scalar value to every point in a region.

$$
    \phi : \mathbb R^3 \rightarrow \mathbb R
$$

or equivalently,

$$
    \phi=\phi(x,y,z).
$$

A scalar field can be imagined as placing a number at every point in space. Scaler fields can be visualized using

- color maps
- contour (level) curves
- contour surfaces
- height plots

### Constant Scalar Field

A constant scalar field (also called a level surface) has the same value everywhere.

$$
    \phi(x,y,z) = C
$$

## Vector Fields

A vector field is a vector-valued function whose input is a point in space.

It assigns a vector to every point in a region.

$$
    \mathbf F : \mathbb R^3 \rightarrow \mathbb R^3
$$

or

$$
    \mathbf F = \mathbf F(x,y,z)
$$

Every point in space has both a magnitude and a direction associated with it. A vector field can also be written in component form as

$$
    \mathbf F = F_x(x,y,z) \hat{\mathbf x}
                + F_y(x,y,z) \hat{\mathbf y}
                + F_z(x,y,z) \hat{\mathbf z}
$$

where each component is a scalar field.

Vector fields are commonly visualized using arrows assigned to every point in space. The arrow direction shows the vector direction, while the arrow length represents its magnitude. Vector fields can also be visualized by

- streamlines
- field lines
- flow maps

### Constant Vector Field

A constant vector field has the same vector everywhere.

$$
    \mathbf F(x,y,z) = \mathbf C.
$$
